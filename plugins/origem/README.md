# Origem — plugin para o Claude

Ideias que viram obras — com origem visível.

## O que faz

- **origem-protocolo** — regras de uso: carregar as obras, ler antes de responder, separar o registrado do novo, nunca gravar sem pedido explícito.
- **/origem-registrar** — prepara uma contribuição, mostra a prévia e grava com comprovante.
- **/origem-retomar** — mostra onde a obra parou, decisões em vigor, questões abertas e próximo passo.
- **/origem-genealogia** — origem, marcos, derivações e créditos de uma obra.

## Requisito

O plugin já traz a conexão com o servidor do Origem (https://lovables-origem-bridge.lovable.app/mcp). Ao usar pela primeira vez, entre com a sua conta do Origem. Contas novas precisam ser aprovadas pelo administrador depois de confirmar o e-mail.
