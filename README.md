# Origem — plugin para o Claude

Ideias que viram obras — com origem visível.

## Como instalar no Claude

1. Crie sua conta no Origem: https://lovables-origem-bridge.lovable.app/cadastro (o acesso é liberado após aprovação).
2. No Claude, adicione este catálogo de plugins pelo endereço do repositório: `fernandohidtec-hash/origem-plugin`
3. Instale o plugin **origem** e entre com a sua conta do Origem quando o Claude pedir.

No Claude Code:

```
/plugin marketplace add fernandohidtec-hash/origem-plugin
/plugin install origem@origem
```

## O que o plugin faz

- **origem-protocolo** — regras de uso: ler antes de responder, separar o registrado do novo, nunca gravar sem pedido explícito.
- **/origem-registrar** — prepara uma contribuição, mostra a prévia e grava com comprovante.
- **/origem-retomar** — mostra onde a obra parou, decisões em vigor, questões abertas e próximo passo.
- **/origem-genealogia** — origem, marcos, derivações e créditos de uma obra.
